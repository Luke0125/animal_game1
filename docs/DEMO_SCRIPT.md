# 5분 시연 대본 (7단계 데모 모드)

> 수업 권장: "5분 안에 모든 요소 시연". 타이틀에서 **데모 모드: ON**을 켜면 맵 오른쪽·전투 화면 위쪽에 보라색 데모 버튼이 나온다.
> (에디터/개발 빌드에서는 데모 모드를 안 켜도 항상 보인다.) 치트는 전부 Core의 `Debug*` 메서드라 정상 진행과 같은 상태를 만든다 — CoreSim `DemoTests`로 검증.

| 시간 | 화면 | 할 일 | 보여 주는 요소 |
|---|---|---|---|
| 0:00 | 타이틀 | **데모 모드 ON** → 새 게임 → 인트로 1~2장 넘기고 "건너뛰기" | 세계관(연구소 탈출·오염·저주), 조작 안내 |
| 0:30 | 종 선택 | 사자(육식)·토끼(초식)·여우(잡식) 선택, 튜토리얼 끔 → 시작 | 12종, 식성 3종, 홀로서기 스킬 미리보기 |
| 0:50 | 유물 장착 | 유물 장착 → 확인 | 지형 미리보기(§11), 유물 슬롯 |
| 1:10 | 맵(탑뷰) | 방향키로 몇 칸 걷고 "몹" 노드로 | 지형 타일맵, 노드 구조, 배고픔 감소 |
| 1:30 | 전투 | 기본 공격 1번(연출·로그) → **[데모] 적 HP 10%** → 정화 선택(확률 %) → 정화 | 턴 순서, 공격/방어/정화/스킬, 정화 확률, 적 스킬 |
| 2:10 | 전투 후 | 열매 먹이기 → 휴식 → 계속 이동 | 식성별 음식, 배고픔/HP 분리 |
| 2:30 | 맵 | **[데모] 조각 +3** → 원석 3종 제작 | 원석 → 시너지(무리사냥/생명의 순환/적응) 한 줄 표시 |
| 2:50 | 맵 → 이벤트 | 데모 패널에서 "굶주린 새끼 여우" 예약 → `?` 노드 → 선택 | 딜레마형 이벤트, 결과 문구 |
| 3:20 | 맵 → 보스 | **[데모] 보스 앞으로** → 보스전 → 로그의 적 스킬 확인 → **[데모] 즉시 승리** | 보스전, 적 AI |
| 3:40 | 작별 | 포식 vs 집 보내기 설명 후 하나 선택 | 핵심 딜레마(§3) |
| 4:00 | 맵 | **[데모] 3스테이지로** → 유물 장착 → 몹 전투 | 파티 1마리 = **홀로서기**(바뀐 스킬·실제 습성·궁지 본능) |
| 4:30 | 전투 | 홀로서기 스킬 1번 사용 → **[데모] 즉시 승리** → (보스까지 가서) 클리어 | 게임 클리어 결과 화면 |

## 시간이 남거나 질문이 나오면
- **[데모] 혼자 남기기**(전투 화면): 1스테이지에서도 홀로서기를 바로 보여 줄 수 있다.
- **매복 예고**: 표범 적이 "노리는 중!"이면 방어로 막는 장면.
- 밸런스 근거: `Tests/CoreSim` 봇 3종 × 2000판 결과(ROADMAP 6단계 표).
