# 화면 레퍼런스 메모 (팀이 준 참고 이미지 2장 요약 — "참고"용, 똑같이 만들 필요 없음)

> 이미지를 매번 다시 올리지 않도록 텍스트로 요약. 평가 기준상 순수 시각 요소는 점수 반영이 안 되므로 **기능이 먼저, 그래픽은 플레이스홀더**로 시작한다.

## 1. 스테이지 맵 (세로 스크롤 한 장)
- 아래→위로 쌓인 떠 있는 섬 4개 = 스테이지 0~3: **들판(숲) → 늪 → 설산 → 사막** (`Balance.StageTerrains`)
- 각 섬: 시작 노드 → 갈림길 노드들 → 맨 위 **보스** 노드(빨간 "보스" 배너). `?` 원형 노드 = 이벤트(최대 1회)
- 섬 오른쪽에 양피지 라벨(지형 이름+아이콘) → 스테이지 입장 전 지형 미리보기(§11)
- 좌하단 **"원석 도감"** 패널: 보유 원석 수, 식성별 원석 슬롯(미획득은 `?`)
- 픽셀아트 풍 → 도입 시 `.claude/skills/2d-pixel-perfect` 참고

## 2. 전투 화면 (사이드뷰)
- 좌상단: 스테이지명 + 한 줄 목표 텍스트 (예: "숲의 오염지 1-2 / 뒤틀린 숲을 정화하자")
- 상단 중앙: **턴 순서 바** — 초상화 원형 아이콘 가로 나열, 적은 빨간 테두리, 현재 차례 ▼ 표시 + "TURN n" → `Battle.TurnQueue`, `Battle.Round`
- 우상단: **적 정보 패널** — 이름, HP바 + 수치, **정화 성공률 %**(현재 행동 동물 기준, `Battle.PurifyChance`), 상태 아이콘(독 등)
- 필드: 아군 왼쪽(현재 차례 머리 위 ▼), 적 오른쪽, 저주받은 적은 붉은 오라
- 하단 아군 카드 ×3: 초상화, 이름, 식성 음식 아이콘(고기/열매), HP바, **배고픔바**, ATK/HP/SPD 숫자
- 하단 중앙: **스테이지 유물** 카드(장착 유물)
- 우하단 커맨드: **기본 공격 / 정화 / 스킬(코스트 or 남은 횟수 표시) / 방어** + 위쪽에 **조합 필살기** 버튼(§4.5 시너지, 원석 해금 — 5단계)
- 이미지의 늑대·Lv 표기는 로스터/기획에 없음 → 무시
