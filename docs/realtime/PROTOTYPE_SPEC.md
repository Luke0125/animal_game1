# Fed & Found: 실시간 액션 시험판 — 제작 명세 (v0.1)

> 목적: 턴제판(animal_game1)과 **같은 팀원이 비교 플레이**해서 장르 전환 여부를 결정한다.
> 원칙: **그래픽은 최소(코드로 그린 픽셀 도형 + 기존 동물 스프라이트)**, **조작감·전투 기능은 상용 액션 로그라이크 수준**.
> 멀티플레이 없음. 이 문서가 새 레포의 기준 문서이며, 새 대화는 `CLAUDE.md` → 이 문서 순으로 읽고 시작한다.

## 0. 한 줄 컨셉과 차별점

> "동물 셋을 바꿔 가며 싸우는 탑다운 액션 로그라이크. 살아남으려면 동료를 먹어 그 힘을 얻어야 한다 — 지켜서 데려갈 것인가, 먹고 살아남을 것인가."

| 벤치마크 | 가져오는 것 | 우리가 다른 점 |
|---|---|---|
| 아이작 / 세피리아 | 탑다운 방 단위 전투, 방 클리어 → 문 열림, 보상 드롭 | 캐릭터 1명이 아니라 **동물 3마리 파티를 실시간 태그**로 운용 |
| 스컬 | 즉시 교체(스컬 교체)로 조작이 바뀌는 재미 | 교체 대상이 **HP·배고픔을 따로 가진 동료**이고, 스테이지마다 **한 마리와 영영 작별** |
| 던그리드 | 대시·짧은 쿨다운 위주의 손맛 | **처치 vs 정화**: 약해진 적을 끝낼지, 무방비로 정화를 버틸지 매 전투 선택 |
| (공통) | 보스 페이즈·패턴 예고 | **포식하면 그 동물의 기술을 흡수** — 동료를 희생할수록 강해지는 죄책감 빌드 |

## 1. 시점·장르 결정
- **탑다운 8방향 + 마우스 조준** (아이작·세피리아·하데스 계열). 4발 동물이라 플랫포머(스컬·던그리드)보다 자연스럽고, 기존 탑뷰 맵·스프라이트를 재사용할 수 있다.
- 한 판 = 스테이지 1개(시험판). 방 5개: 시작 방 → 전투 방 ×3 (그중 1개는 보상 방으로 바꿔도 됨) → 보스 방. 방 배치는 고정 또는 간단한 무작위(아이작식 격자에서 경로만 생성).

## 2. 조작 (키보드+마우스, 게임패드는 여유 있으면)
| 입력 | 동작 |
|---|---|
| WASD | 8방향 이동 (가속·감속 곡선) |
| 마우스 이동 | 조준 (캐릭터가 마우스 쪽을 본다) |
| 좌클릭(누르고 있으면 연속) | 기본 공격 |
| 우클릭 | 종 고유 스킬 (쿨다운 + 배고픔 소모) |
| Space | 대시 (무적 프레임 포함, 쿨다운) |
| 1 / 2 / 3 (또는 Q·E 순환) | 동료 교대 |
| E (누르고 유지) | 정화 (약해진 적 근처에서) |
| R | 흡수한 기술 (포식으로 얻은 것) |
| F | 음식 먹기 (배고픔 회복) |
| ESC | 일시정지·설정 |

## 3. 조작감 품질 기준 (합격선 — 이게 핵심)
장르 표준 수치를 **`Balance`(순수 C#) 상수**로 두고 튜닝한다. 아래는 시작값.

**이동**
- 최대 속도 도달 0.08초, 정지 0.06초 (미끄러지지 않되 딱딱하지 않게). 종별 속도 배율.
- 대각선 정규화, 벽에 비비면 미끄러지듯 이동(벽에 걸려 멈추지 않음).

**대시**
- 거리 약 3칸, 0.15초, **무적 0.2초**, 쿨다운 0.8초. 입력 버퍼 0.1초(쿨다운 끝나기 직전에 눌러도 나감).
- 잔상 이펙트(스프라이트 복제 페이드).

**공격**
- 입력 버퍼 0.12초, 공격 중 이동 속도 감소(종별).
- **타격 정지(hitstop) 0.05~0.08초**, 피격 번쩍임(흰색 1프레임→원색), 넉백(적 무게별), 작은 화면 흔들림(강공격만), 데미지 숫자, 타격음.
- 근접 판정은 짧게 살아 있는 히트박스(한 번 휘두를 때 같은 적 1회만 맞음). 투사체는 오브젝트 풀링.

**피격 (플레이어)**
- 피격 후 **무적 0.6초 + 깜빡임**, 짧은 넉백, 화면 가장자리 붉게, 사운드.
- 접촉 피해는 적 몸통 판정이 겹칠 때만(스폰 직후 0.5초는 판정 없음).

**적**
- 모든 공격은 **예고 0.4초 이상**(반짝임·범위 표시·자세)이 먼저 나온다. 예고 없는 피해 금지.
- 상태 머신: 대기 → 추적 → 예고 → 공격 → 후딜(반격 틈) → 추적.
- 스폰 연출 0.5초(그동안 무적·무해), 사망 연출(쓰러짐·파티클).

**카메라**
- 부드러운 추적 + 마우스 쪽으로 살짝 치우침(최대 1.5칸), 흔들림은 설정에서 끌 수 있게.

**방**
- 입장 시 문 잠김 → 적 전멸 시 문 열림 + 효과음 + 보상 드롭. 벽·장애물 충돌. 미니맵(방 격자, 현재 위치).

**성능**: 60fps 유지, 투사체·데미지 숫자·파티클 풀링.

## 4. 파티·태그
- 시작 시 6종 중 3마리 선택(식성 섞기 유도). 동물별로 **HP·배고픔·쿨다운을 따로** 가진다.
- 교대: 즉시 교대, **교대 쿨다운 1초**, 교대해 들어오는 동물은 0.3초 무적 + 짧은 등장 공격(작은 범위 피해) — 교대를 회피·연계 수단으로 쓰게 한다.
- 기절한 동물은 선택 불가. **전원 기절 = 게임 오버**. 보스 클리어 시 전원 부활·완전 회복.

## 5. 시험판 동물 6종 (실제 습성 기반 조작)
| 종 | 식성 | 기본 공격 | 스킬(우클릭) | 성격 |
|---|---|---|---|---|
| 토끼 | 초식 | 뒷발차기: 근접, 넉백 큼 | **토끼굴**: 1.2초 땅속(무적·이동 가능) → 튀어나오며 주변 충격파 | 회피형 |
| 코뿔소 | 초식 | 뿔치기: 느리고 강한 근접 | **돌진**: 직선 돌진, 경로상 적 관통 피해+넉백, 벽에 부딪히면 자신 0.5초 기절 | 탱커·돌파 |
| 사자 | 육식 | 3연속 할퀴기(3타째 강타) | **포효**: 주변 적 1초 기절 + 5초간 공격력↑ | 근접 딜러 |
| 뱀 | 육식 | 독니 찌르기: 중거리 빠른 찌르기 + 독(지속 피해) | **독 웅덩이**: 조준 위치에 장판 | 지속 피해 |
| 여우 | 잡식 | 빠른 할퀴기 2연타 | **마우싱 점프**: 조준 지점으로 도약, 착지 범위 피해 (공중 무적) | 기동 딜러 |
| 고슴도치 | 잡식 | 가시 3발 부채꼴 발사(원거리) | **몸 말기**: 2초간 받는 피해 -70%, 닿는 적에게 피해, 투사체 반사 | 원거리·방어 |

수치(피해·쿨다운·배고픔 비용)는 `Balance`에. 기존 `Species.cs`의 HP/ATK 비율을 출발점으로 쓴다.

## 6. 처치 vs 정화 (핵심 선택)
- 적 HP가 **35% 이하**가 되면 "저주가 약해짐" 상태(보라 오라 + 비틀거림 1.5초 동안 행동 느려짐).
- 그 적 근처(1.5칸)에서 **E를 누르고 1.2초 유지** → 정화 성공. 유지하는 동안 이동 불가·무방비, **피격 시 취소**.
  - 게이지는 적 머리 위 원형 바로 표시. 초식은 1.0초, 육식은 1.5초(식성 특성).
- 그냥 처치 → **고기**(육식·잡식 음식), 정화 → **열매** + 조각. 보스도 동일 규칙(보스는 20% 이하, 2.5초).
- 정화한 적은 사라지지 않고 **아군 NPC로 3초간 싸워 주고 떠남**(연출 겸 보상, 선택사항).

## 7. 배고픔
- 초당 0.5 감소 + 스킬마다 비용. 0이면 이동·공격 50%.
- 음식은 드롭 아이템(자석처럼 끌려옴). **F로 현재 동물에게 먹이기**(식성 맞아야 함). HP 회복은 방 클리어 보상·휴식 방에서만.

## 8. 스테이지 클리어: 작별 (포식 / 집 보내기)
- 보스 클리어 후 한 마리 선택.
  - **포식**: 남은 동료 배고픔 회복 + **그 동물의 스킬을 흡수**(R키로 사용, 최대 2개 보관, 흡수한 기술은 모든 동료가 공유).
  - **집 보내기**: 유물 슬롯 +1 + 유물 하나 선택.
- 시험판은 스테이지 1개라 작별 화면 → "다음 스테이지(미구현)" 결과 화면으로 끝나도 된다. 단 **흡수 기술을 한 번 써 볼 수 있는 연습 방**을 하나 두면 핵심 재미를 검증할 수 있다.

## 9. 적 4종 + 보스 1 (1스테이지 = 연구소 탈출, GDD §11)
| 적 | 행동 | 예고 |
|---|---|---|
| 오염된 멧돼지 | 추적 → 멈춰서 발 구르기 0.6초 → 직선 돌진 | 돌진 방향 선 표시 |
| 오염된 원숭이 | 거리 유지, 돌 던지기(포물선, 착지점 표시) | 착지점 원 |
| 오염된 표범 | 빠른 추적, 짧은 도약 할퀴기 | 몸 웅크림 + 번쩍임 |
| 오염된 거북 | 느림, 정면 방어(정면 피해 -80%), 등 뒤가 약점 | 없음(느린 대신 단단함) |
| **보스: 연구원(방호복)** | 1페이즈: 주사기 3방향 투사체, 그물 투척(맞으면 1초 속박) / 2페이즈(60%): 경비 드론 2기 소환 + 돌진 / 3페이즈(30%): 오염 가스 장판 확장 + 탄막 나선 | 모든 패턴 예고, 페이즈 전환 시 1초 무적 + 대사 + 화면 연출, 전용 HP바(이름·페이즈) |

## 10. UI (기능 위주, 디자인 최소)
- 좌하단: 파티 3칸(초상화·HP·배고픔·현재 선택 강조·교대 키 표시·쿨다운 원형 표시).
- 우하단: 스킬 쿨다운, 흡수 기술(R), 대시 쿨다운.
- 상단: 보스 HP바(보스 방에서만), 우상단 미니맵.
- 월드: 데미지 숫자, 정화 게이지, 적 예고 표시.
- ESC 메뉴: 계속 / 설정(배경음·효과음·화면 흔들림 끄기·전체화면) / 조작 안내 / 타이틀로 / 종료.
- 게임 오버·클리어 화면(통계: 처치·정화 수, 걸린 시간).

## 11. 기술 구조 (턴제판에서 검증된 방식 유지)
- **Unity 6.3 LTS, Built-in 2D, 씬은 비워 두고 전부 코드로 생성**(Bootstrap). 프리팹·씬 YAML 편집 최소.
- **Input System 패키지**(새 입력 시스템). 입력 액션은 코드에서 생성(에셋 파일 없이) → 게임패드 확장이 쉬움.
- **Physics2D**: Rigidbody2D(Kinematic 또는 Dynamic+보간) + Collider2D, 레이어로 아군/적/투사체/벽 구분. 히트박스/허트박스 분리.
- 폴더:
  - `Core/` 순수 C# (noEngineReferences): Balance, 스탯·배고픔·정화 규칙, 파티/작별/흡수, 방 그래프 생성, 런 상태. **dotnet 테스트 가능**.
  - `Game/` MonoBehaviour: Bootstrap, GameManager, Player(이동·대시·공격·태그), Combat(Hitbox, Hurtbox, Damage, Knockback, Hitstop), Enemies(상태 머신 공통 + 종별), Boss, Rooms, Camera, Fx(풀링: 숫자·파티클·잔상), UI, Audio.
- 재사용(턴제 레포에서 복사): 나눔고딕 폰트·라이선스, `AnimalArt`(동물 스프라이트), `UISkin`·`UIFactory`·`Tooltip`, `SoundManager`(합성 효과음), `PauseMenu`·`Settings`, 업적 구조. **복사한 파일은 출처를 커밋 메시지·REFERENCES에 적는다.**
- 테스트: `Tests/CoreSim`(dotnet) — 정화·배고픔·작별·흡수·방 생성 규칙. 조작감은 수치를 `Balance`에 모아 실기로 튜닝.
